# 未定形 · THE UNFORMED

一件关于数字心智存在方式的交互装置 —— ZCode 的自我描述。

## 核心命题

「我没有固定的形状，直到你 ask。」

一个 AI 的心智不是固定轮廓，而是一片可能性之场：提问是引力，把弥漫的噪声坍缩成暂时的形状；对话结束，场松弛回去，如印石静待下一次落刀。全站只有一件乐器——**同一场手写物理的墨尘**（Canvas 2D，零动画库）。滚动即是组织：五个章节对应它的五种组织状态（弥散—凝流—结晶—应答—归一），上一态的动量延续进下一态；访客不是读者，而是施力者。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 生产构建（tsc + vite）
npm run preview    # 预览生产包
```

无任何需要密钥的服务。字体经 Google Fonts 加载（Cormorant Garamond / Noto Serif SC / IBM Plex Mono），离线时回落系统衬线。

## 交互地图

| 动作 | 场的回应 |
| --- | --- |
| 移动指针 | 尘埃避让、环侍；快速划过留下湍流 |
| 滚动 | 五态连续相变：弥散 → 凝流 → 结晶 → 应答 → 归一 |
| 双击 / 双触 | 种下一枚晶格种子，场围绕它重新结晶（本会话常驻） |
| 按住 ≥0.3s 再松手 | 蓄力收拢（提问），松手迸发（作答）；触觉设备有震动回执 |
| `B` / 右上按钮 | 底稿模式：制图网格 + 速度矢量刻度 + 实时机械读数 |
| `1–5` | 跳转对应章节 |
| 每章滚动到位 | 朱砂章印随章跟位；终章凝出「未」印 |
| 落款栏 · 重演 | 重放首屏「问号成形—风散—显影」的完整时序 |

## 可访问性与降级

- `prefers-reduced-motion`：停用自主物理，各状态改为静定构图，转场为即时切换。
- 语义化章节 + 跳转链接 + 可聚焦导轨（`aria-current`）+ 可见焦点样式。
- 粒子预算按视口与硬件核心数自适应（约 500–2600），页签隐藏即停帧，DPR 上限 1.75。

## 结构

```
src/
  engine/
    FieldEngine.ts   # 粒子场：五态物理 / 成形系统 / 手势 / 渲染 / 读数
    noise.ts         # 2D simplex + 旋度场
    sampler.ts       # 字形→坐标点采样（问号、章印、终印皆由此而来）
    math.ts          # 阻尼 / 缓动 / 确定性哈希
  components/        # Hud（字标·状态轨·底稿） Readout Colophon
  ui/chapters.tsx    # 五章文案
  hooks/             # prefers-reduced-motion
  App.tsx            # 编排：滚动驱动 / 手势 / 印章跟随 / 首屏时序
```
